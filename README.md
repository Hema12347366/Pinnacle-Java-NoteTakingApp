# Pinnacle-Java-NoteTakingApp

 Task 2 – Note Taking Application using Java

 Description
This is a simple Java console-based Note Taking Application developed using Java. The application allows users to add, view, search, and delete notes through a menu-driven interface.

Features
- Add Notes
- View Notes
- Delete Notes
- Search Notes
- User-Friendly Menu

Technologies Used
- Java
- Scanner Class
- ArrayList
- Conditional Statements
- Loops
